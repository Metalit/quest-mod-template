# Quest Mod Template

A template for creating Beat Saber mods for standalone Oculus Quest, intended to be used with [QPM](https://github.com/QuestPackageManager/QPM.CLI/) templatr.

For a full guide on using this template, visit the [BSMG Wiki](https://bsmg.wiki/modding/quest/intro.html).

Created by [Metalit](https://github.com/Metalit) based on previous work by [Lauriethefish](https://github.com/Lauriethefish), [Fern](https://github.com/Fernthedev), and [Bobby Shmurner](https://github.com/BobbyShmurner).
